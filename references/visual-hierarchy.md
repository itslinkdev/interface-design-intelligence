# Visual hierarchy and compositional polish
**Use when:** cluttered layouts, dashboards, product cards, CTA hierarchy, redesigns.

1. Identify the one question the user is trying to answer, then rank visible information: essential → supporting → optional. Express rank through typography, contrast, position, and whitespace, not color alone.
2. Give each decision context a distinct primary action; secondary actions remain findable. Do **not** remove legitimate features simply to produce a cleaner screenshot.
3. Use meaningful grouping, aligned edges, stable grids, predictable spacing, and consistency across sibling components.
4. For product cards, lead with understandable title, price, key variants/availability, then supporting metadata; retain taxes/shipping or other required decision facts. Clarify promotion semantics rather than inventing them.
5. Keep image controls unobtrusive but discoverable and accessible. Don't sacrifice checkout or cart navigation for a minimal mockup.
6. Selected items, current nav destinations, and the most critical values must be distinguishable at a glance; preserve meaningful hierarchy in compact/zoomed layouts.
7. Use repeated visual language (tokens, icon stroke, states) across an application. Treat a redesign as successful only if it improves comprehensibility **and** preserves task completion.

**Review prompts:** What do I notice first? Is that what matters? Is the main action unmistakable? Which removed element served a real function? Are related items close? Does visual style remain consistent with adjacent screens?

Source examples: ecommerce before/after, title and price grouping, clean action bar, typography and consistency carousels.
