# Security policy

Please do not post credentials, exploit details involving real users, or private files in public issues. Use GitHub's private vulnerability reporting for this repository if enabled; otherwise contact the maintainer through a private GitHub channel before disclosing sensitive information.

This repository contains local, optional Python utilities. They should not need network access, provider tokens, or write access outside explicitly chosen output paths. Treat external skills and pull requests as untrusted code before running them.

Public releases should exclude: third-party social-media screenshot crops, API keys, `.env` files, access tokens, personal screenshots, user-provided assets without permission, and unverifiable benchmark claims.
