# Changelog

## 1.3.0 — slider interactions and publishing readiness
- Added opt-in native-first slider guide: drag without lag, easing only for meaningful snap/target changes, and accessibility/low-power tests.
- Added dependency-free offline slider/easing demonstration and focused regression tests; source video itself is not bundled.
- Improved agent-skill metadata validation and installation/publishing documentation, including skill vs plugin distinction.
- Kept existing five visual styles, 62 pattern IDs and nine platform adapters; no always-loaded slider examples.

## 1.2.0 — dark UI quality and purposeful motion (low-context)
- Added **opt-in** dark-mode guide with tonal surface hierarchy, contextual black/white/chroma, accessible contrast, theme choice and official sources.
- Added an optional stdlib WCAG solid-color contrast CLI supporting foreground alpha, plus an original offline dark-mode example.
- Expanded the existing motion reference with concise easing-by-intent (linear, ease-in, ease-out, ease-in-out, overshoot, elastic, bounce, steps), without introducing an always-loaded module.
- Added dark-mode regression/negative-control tests and evaluation scenarios. Original screenshots/video are not redistributed.
- Preserved five original visual recipes, all 62 patterns and all nine adapters. Core remains small and module reads remain conditional.

## 1.1.0 — selective visual directions
- Added five original opt-in recipes: Liquid Glass, Analog Grain, Chrome Typography, Pixel Accents, and Editorial Serifs.
- Added local `find_style.py` keyword routing, a five-row lightweight catalog, and nine automatic package/route tests in total.
- Added an original responsive CSS-only style gallery (not redistributed screenshots), accessibility and performance fallbacks.
- Preserved all 62 UX patterns, all 14 references and all 9 stack adapters; core remains under the instruction-size cap.
- Expanded static footprint reporting, offline checks and candid benchmark documentation. Comparative model quality remains unmeasured.


## 1.0.0 — initial public edition
- Compact task-routed Agent Skill for web, desktop and mobile UI work.
- 14 context-optional design modules and 9 lightweight platform adapters.
- 62 searchable text-only design patterns; original SVG graphics replace third-party screenshots.
- Optional offline CSS token generator, integrity checks, unit tests and honest benchmark templates.
- MIT license, contributions and security policies.

The private working pack previously contained screenshots; they are **not** part of this public release.
