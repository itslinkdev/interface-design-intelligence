# Jetpack Compose
**Use when:** designing Android Jetpack Compose screens.
- Follow Material 3 patterns where applicable; use semantic color scheme, typography and reusable composables.
- Use state hoisting and stable keys; avoid expensive recomposition and blocking work on main thread.
- Apply correct semantics, TalkBack labels, keyboard order, focus targets and minimum interactive sizes.
- Check system bars, insets, font scale, dark mode, RTL and device-width variations.
