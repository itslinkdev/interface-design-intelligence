# SwiftUI
**Use when:** building SwiftUI views.
- Prefer native navigation, sheets, alerts, controls and accessibility labels. Support Dynamic Type and VoiceOver.
- Use semantic system colors, environments and appearance; test dark mode and increased contrast.
- Structure reusable views around state ownership; avoid unsupported lifecycle side effects and excessive view recomposition.
- Validate safe areas, input focus, keyboard, pointer and reduce-motion for target Apple platforms.
